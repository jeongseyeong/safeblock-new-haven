#IntersectionCrashesKSIPed/BikeExcess/yrCost/yr

Real data: UConn CT Crash Data Repository (police-reported crashes), snapped to OpenStreetMap intersections within 30 m. Score = empirical-Bayes expected crashes/yr minus SPF prediction, where the SPF uses an exposure proxy (sum of road-class weights of incident streets) because no traffic counts are used. Costs: USDOT BCA Guidance 2025 Update II, Table A-1 (2023 $), applied at each crash's most severe injury (one victim per crash), so they are rough. KSI = killed or seriously injured.
